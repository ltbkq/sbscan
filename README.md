# sbscan

> 开源、离线、无广告的文档扫描应用。核心技术对标并超越 CamScanner。

## ✨ 特性

| 功能 | 说明 |
|---|---|
| 📷 智能扫描 | 实时文档边缘检测，**稳定性自动拍摄**（无需按快门） |
| ✂️ 透视矫正 | 自动检测四角 + 手动拖拽微调，一键拉正 |
| 🎨 图像增强 | **去阴影**（光照估计）、**CLAHE-lite** 局部对比度、灰度、黑白、锐化 |
| 📄 可搜索 PDF | 导出 PDF 自带**隐形文字层**，全文可搜索/复制 |
| 🔍 本地 OCR | 中英文识别，**无限次、免费、离线** |
| 📚 文档管理 | 多页文档、重命名、删除、缩略图 |
| 🔒 隐私优先 | **零网络请求、零追踪、零广告**。所有数据仅存于本机 |

## 与 CamScanner 对比

| | CamScanner 免费版 | sbscan |
|---|---|---|
| 广告 | 开屏/信息流/推送广告 | **无** |
| 去阴影 | 会员功能 | ✅ 免费 |
| 可搜索 PDF | 会员功能 | ✅ 免费 |
| OCR | 有次数限制（云端计费） | ✅ 无限本地识别 |
| 自动拍摄 | 会员功能 | ✅ 免费 |
| 联网/追踪 | 广告 SDK + 归因 + OAID | **完全离线** |
| 开源 | 否 | ✅ Apache-2.0 |

## 🛠 技术栈

- Kotlin + Material 3
- CameraX（预览 / 拍摄 / 实时分析）
- 自研图像处理引擎（无 OpenCV 重依赖）：
  - 边缘检测：Sobel + Otsu + 连通域 + 凸包 + 旋转卡壳最小外接矩形
  - 去阴影：灰度形态学闭运算估计背景光照 + 归一化
  - 对比度：CLAHE-lite（分块直方图均衡 + 双线性插值）
  - 二值化：积分图自适应局部阈值
- ML Kit 文字识别（bundled 模型，离线运行，无需 Google 服务）
- Android PdfDocument（可搜索文字层）

## 🚀 构建

```bash
./gradlew assembleDebug
# APK 位于 app/build/outputs/apk/debug/
```

最低支持 Android 7.0 (API 24)，无需 root、无需 Google 服务。
